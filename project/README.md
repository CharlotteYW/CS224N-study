Week 13 is the proposal. Week 14 is a first working slice and a synthesis of the course. A real GPT-2 project can run longer than week 14. The tracker should say in progress rather than pretend it is done.

## Why this is in the course

The project is where the pieces meet: a transformer, a training objective, an evaluation, and a writeup that says what you changed. The default 2025 project is a minimal GPT-2. A custom project is allowed only if the question is already concrete.

## Done when

proposal.md is filled, a small training or fine-tune has run, and reviews/synthesis.md connects this project back to word vectors and attention.
