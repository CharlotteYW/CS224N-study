## Why this unit exists

This session makes tokenizer and model interfaces concrete. Inspect official assignment dependencies separately; library use is not proof of architecture understanding.

## Concepts you must be able to explain

- A tokenizer turns text into ids, and special tokens are part of the interface
- A pretrained checkpoint is weights plus a config, not a new model class you write from scratch
- The difference between the forward pass you saw in Lecture 8 and model(**batch)
- Where fine-tuning updates weights, and where you would freeze them
