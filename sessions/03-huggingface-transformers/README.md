Week 15: explore tokenizers and model interfaces after L08–09. This is useful practice; the 2025 A4 starter should not be assumed to depend on Hugging Face.

## Why this is in the course

This session makes tokenizer and model interfaces concrete. Inspect the official assignment requirements separately; using a library does not establish understanding of the architecture.

## Done when

You can load a small model in the Colab, run one batch, and name the tensors that came out.
