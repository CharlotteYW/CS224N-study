# Summary: Reasoning and agents

Status: Not Started

## Why this unit exists

A next-token model becomes an agent when the text includes actions, tool results, and a loop. This lecture is that systems picture, built on top of prompting and post-training rather than a new architecture.

## Concepts you must be able to explain

- A reasoning trace as tokens the model produces before an answer
- Acting with tools: the model emits an action, an environment returns text, the model continues
- What a benchmark for agents has to include that MMLU does not
- The difference between reciting a solution pattern and using a tool because the state changed
