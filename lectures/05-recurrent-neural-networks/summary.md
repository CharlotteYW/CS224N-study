# Summary: Recurrent neural networks and language models

Status: Not Started

## Why this unit exists

Language is ordered. A language model is a distribution over the next word. An RNN is the first architecture in the course that carries a hidden state through that order, and the first one that breaks when the sequence gets long.

## Concepts you must be able to explain

- A language model as P(next word | previous words)
- Why n-gram models get sparse as the context grows
- The RNN recurrence: the same function, a new input, an updated hidden state
- Backpropagation through time
- Vanishing and exploding gradients, and what each one does to learning long-range patterns
