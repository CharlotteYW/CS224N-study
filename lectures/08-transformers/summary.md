# Summary: Transformers

Status: Not Started

## Why this unit exists

The transformer removes recurrence and keeps attention, applied to every position. This is the model the rest of the course, and Assignment 4, are about.

## Concepts you must be able to explain

- Self-attention: each position queries the whole sequence, including itself
- Scaled dot-product attention, and what the scale is for
- Queries, keys, and values as three linear maps of the same input
- Multi-head attention as several of those maps
- Why a position representation has to be added once recurrence is gone
- Residual connections and layer normalization as the path that keeps a deep stack trainable
