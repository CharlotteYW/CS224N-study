# Summary: Question answering and knowledge

Status: Not Started

## Why this unit exists

A language model stores some facts in its parameters and still misses or invents others. Retrieval is how you hand it a passage. This is the lecture that connects week-1 vectors (similarity search) to systems people actually ship.

## Concepts you must be able to explain

- Span selection on a given passage versus open-domain question answering
- Dense retrieval: embed the question and the passages, then search
- Retrieval-augmented generation: the generator conditions on what was fetched
- Parametric memory versus a datastore, and what each one can update
- Lost-in-the-middle: a long context is not the same as a used context
