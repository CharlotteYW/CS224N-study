Half of the graded course is a project. This recording also continues attention, which is needed before A3. Its project portion helps you choose a testable question; implementation comes after the core assignments.

You can explain the attention material, draw its role in an encoder-decoder, and state a tentative project question with a possible baseline. The final scope decision is planned for Week 25.
