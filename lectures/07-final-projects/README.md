About 90 minutes. This is a planning lecture. Do not let it displace Lecture 8.

## Why this is in the course

Half of the graded course is a project. This lecture is how to choose a question you can finish, and how the default project is shaped. You will not build it until the transformer assignments are done.

## Done when

You can say which project you are leaning toward and what the first baseline would be. The decision can wait until week 13.
