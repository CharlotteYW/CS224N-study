Week 06: study parsing alongside the PyTorch session, then begin the A2 parser milestones.

## Why this is in the course

This is the first full NLP task in the course: a sentence has structure, and a small neural net scores the next action of a parser. It is also the coding half of Assignment 2.

## Done when

You can say which action a transition-based parser is scoring, and what stack and buffer hold, without reading the slide.
