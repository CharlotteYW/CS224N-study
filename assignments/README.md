# Assignments

Complete one coherent set: **Winter 2025**, with independent written and programming
work. [COURSE_MAP](../COURSE_MAP.md) documents the different 2026 A3/A4 sequence.

| Assignment | Prerequisites | Plan weeks | Active effort |
| --- | --- | --- | --- |
| [A1: Word vectors](a1-word-vectors/README.md) | L01–02, NumPy | 02–03 | 8–12 h |
| [A2: Word2Vec and dependency parsing](a2-word2vec-and-dependency/README.md) | L01–04, PyTorch | 05–08 | 18–24 h |
| [A3: NMT](a3-neural-machine-translation/README.md) | L05–07, attention, convolution primer | 11–13 | 20–26 h plus compute |
| [A4: Self-attention, Transformers, pretraining](a4-transformers/README.md) | L08–09, PyTorch | 16–18 | 20–26 h plus compute |

Official instructions and starter links are in each README. Keep downloads, solution
code, written answers, and checkpoints in ignored `work/` directories. summaries/QA
are safe learning records, not copies of official answers. The learner runs applicable
checks and reports actual evidence. Follow the course's AI-use and TA code-review
boundaries in [AGENTS.md](../AGENTS.md); no solution generation or publication.

Milestone completion requires an assessment and explicit learner sign-off. The broader
after-A4 checkpoint occurs in Week 21 because it also covers post-training/evaluation.
